as in several Proxmox LXCs (until I inevitably migrate that machine to just NixOS).

_A word of caution_: I am an amateur at NixOS so there are almost certainly issues within. Do not outright copy as you may be setting yourself up for current and future issues. Please see the resources section below instead.

# Structure

- *[flake.nix](./flake.nix)* is the primary entrypoint for NixOS, defines inputs (including where packages are coming from generally) and outputs for `nixosConfiguration` and `homeConfiguration`.

- *[flake.lock](./flack.lock)* pins external inputs to specific versions/git commits. Auto-generated when updating `nix flake`

- `hm/` Home Manager modules. These are modules installed for users of my machines. Each file manages or configures a user-level package(s) or set of features.

 - `hm/sway/` Sway wl compositor / window manager configurations. Contains all associated configurations and scripts.

- `hosts/` Machine definitions. Each directory contains modules which set the core configuration of each machine and imports system-level packages from `sys/`. Primarily configuring hardware, base system settings, and general user/superuser roles. Contains `hardware-configuration.nix`, which is initially auto-generated by NixOS.

- `overlays/` Package modifications. Defines custom package overlays to add, modify, or inject packages into the `nixpkgs` instance.

- `secrets/` Secret management (using [agenix](https://github.com/ryantm/agenix)). Contains files which define (public) keys and encrypted `.age` outputs, decryped at runtime.

- `style/` Theming and such. contains main stylix config, any personally defined themes, wallpapers, etc.

- `sys/` System modules. These are modules installed machine-wide on machines which opt in to them in `hosts/`.

- `sys/services` Services I run on my network. Realistically these should just sorta be in `sys/` but I like some semantic separation between "things I'm using" and "things I'm sharing"

- `users/` Home Manager entrypoints. Contains user configuration and imports user-level modules from `sys/`.
